# Reflexão

O conflito aconteceu porque as duas pessoas alteraram a mesma linha do README.md
sem que uma delas tivesse atualizado o repositório antes com git pull.

Para resolver o conflito, conversamos e decidimos qual versão deveria permanecer
no arquivo final.

Em um projeto real, tentaríamos evitar conflitos dividindo melhor as tarefas,
comunicando quais arquivos estamos alterando e fazendo git pull com frequência.
Também poderíamos trabalhar em branches diferentes e usar pull requests para
organizar as alterações.
